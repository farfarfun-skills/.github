# .github

farfarfun-skills 组织的 Community Health Files 仓库，只承载组织主页，不含 Skill 内容。

## Usage

[`profile/README.md`](profile/README.md) 会自动渲染到
[组织主页](https://github.com/farfarfun-skills)。要改主页展示的内容，直接编辑该文件并提交。

仓库列表是**手工维护**的，不会自动跟随组织内仓库变化。新 fork 进来或自研 Skill 新增镜像后，
需要回来补一行。

## 关于 farfarfun-skills

面向 AI 编码 Agent 的 Skills 聚合镜像组织：社区热门 Skill 的 fork + [farfarfun-skill](https://github.com/farfarfun-skill)
自研 Skill 的镜像，由 [`action-daily`](https://github.com/farfarfun-skills/action-daily)
每小时跟上游同步，并整体镜像到 [gitee.com/farfarfun-skills](https://gitee.com/farfarfun-skills)。

本仓库自身也在镜像范围内（`action-daily` 的 Daily sync 覆盖组织内所有仓库，不只 fork）。
