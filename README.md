# .github

farfarfun-skills 组织的 Community Health Files 仓库，仅承载组织主页，不包含 Skill 内容。

## Usage

[`profile/README.md`](profile/README.md) 会自动渲染至
[组织主页](https://github.com/farfarfun-skills)。如需调整主页展示内容，直接编辑该文件并提交即可。

其中的仓库列表为**手工维护**，不会自动跟随组织内仓库变化。新增 fork 或自研 Skill 镜像后，
需在该列表中补充对应条目。

## 关于 farfarfun-skills

面向 AI 编码 Agent 的 Skills 聚合镜像组织，收录社区热门 Skill 的 fork 与
[farfarfun-skill](https://github.com/farfarfun-skill) 自研 Skill 的镜像，由
[`action-daily`](https://github.com/farfarfun-skills/action-daily) 每小时与上游同步，
并整体镜像至 [gitee.com/farfarfun-skills](https://gitee.com/farfarfun-skills)。

本仓库自身亦在镜像范围内——`action-daily` 的 Daily sync 覆盖组织内全部仓库，而非仅 fork。
